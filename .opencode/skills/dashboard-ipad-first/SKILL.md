# Dashboard: iPad-first, zero-build

## Hard constraints (from openspec/specs/dashboard/spec.md)
- Pure HTML/CSS/JS. No frameworks, no bundlers, no CDN dependencies.
- Read-only: the page only fetches deals.json — never writes anywhere.
- deals.json is the ONLY data source; never invent fields the backend
  does not export. Shape changes require an OpenSpec change touching
  backend + frontend + contract test together.

## iPad rules
- Touch targets >= 44x44pt; no hover-only affordances.
- Responsive grid: 1 column portrait-phone, 2 portrait-iPad,
  3 landscape-iPad (CSS grid + minmax, no JS media logic).
- Test mentally against Safari: no bleeding-edge APIs without fallback.

## Behavior rules
- Empty deals[] renders a friendly empty state, never a blank page.
- fetch() failures render an error state with the last generated_at
  if available; never an uncaught exception.
- Sparklines are inline SVG generated by pure functions (testable in
  the console): normalize trend[] into a 100x28 viewBox polyline.
